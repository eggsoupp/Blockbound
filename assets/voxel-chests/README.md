# Low-resolution voxel chests

Six MagicaVoxel VOX v150 models, one model per file. Basic: wood and iron; mythical: purple, gold and teal; blackish: charcoal, silver and muted magenta.

Each chest is 24 voxels wide. Bodies and barrel lids are hollow shells to keep voxel counts low. Open variants have a matching lid rotated 90 degrees around the rear hinge. Z is up; the front faces negative Y. A shared palette is embedded in every file.

The PNGs are orthographic previews generated directly from the voxel data. Run build_chests.py with Python and Pillow to rebuild. Binary structure, bounds, palette indices and counts are checked during generation.
