BLOCKBOUND PIXEL UI KIT

Every screen below is built only from the generated sprites, sliced the same way Roblox's SliceCenter slices them, at the in-game scale (one texel = 3px). Hover and click buttons, tabs, toggles, rows and arrows to see each state.

Text uses Press Start 2P, which is Roblox's built-in Arcade font. Item pictures are placeholders; in game the slots keep showing your own item thumbnails.
